Serial manipulators from Denavit–Hartenberg parameters.

  • Forward and inverse kinematics — position and orientation.
  • Euler–Lagrange dynamics · Jacobians · inverse velocity.

beam_tools

↗ python

Symbolic Euler–Bernoulli beams via Macaulay singularity functions.

  • Closed-form shear, moment, slope, and deflection.
  • Determinate and hyperstatic, with automatic compatibility equations.
  • Point, distributed, and triangular loads plus applied moments.

Embedded control 2 repos

prometheus

↗ c / esp32

ESP32 temperature loop with MQTT telemetry — with UFMG's GREA group.

  • Discrete PID, anti-windup and saturation behind a 2nd-order IIR pre-filter.
  • Automatic open-loop → closed-loop handover near setpoint.
  • Dual-core FreeRTOS: control on core 0, MQTT on core 1. Remote tuning, no reflashing.
CESP-IDFFreeRTOSMQTT

fpwm-signal-generator

↗ c / esp32

ESP32 function generator — digital systems and power electronics.

  • Sine, sawtooth, triangle, and square via PWM and hardware timers.
  • Frequency error below 1% across the tested range.
  • Buttons and a 16×2 LCD on a custom development board.
