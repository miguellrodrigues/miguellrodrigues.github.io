robotic_tools

↗ python

Symbolic and numerical analysis of serial manipulators from Denavit–Hartenberg parameters.

  • Forward & inverse kinematics, position and orientation.
  • Forward dynamics via Euler–Lagrange; Jacobians and inverse velocity kinematics.
  • Gradient-descent and evolutionary IK solvers — plug in any DH table.
PythonSymPyNumPy

prometheus

↗ c / esp32

Closed-loop temperature controller on ESP32 with MQTT telemetry, built with UFMG's GREA research group.

  • Discrete PID with anti-windup and output saturation behind a 2nd-order IIR pre-filter.
  • Auto transition from open-loop warm-up to closed-loop near setpoint.
  • Dual-core FreeRTOS — control on core 0, MQTT on core 1; remote setpoint/config, no reflashing.
CESP-IDFFreeRTOSMQTT

beam_tools

↗ python

Symbolic Euler–Bernoulli beam analysis using Macaulay singularity functions.

  • Closed-form shear force, bending moment, slope, and deflection.
  • Statically determinate and hyperstatic beams, with automatic compatibility equations.
  • Point, distributed, and triangular loads plus applied moments.
PythonSymPy

fpwm-signal-generator

↗ c / esp32

Function generator on ESP32 applying digital-systems and power-electronics concepts.

  • Sine, sawtooth, triangle, and square waveforms via PWM and hardware timers.
  • Frequency error below 1% across the tested range.
  • Buttons and a 16×2 LCD interface on a custom development board.
CESP-IDF

Research & publications

My academic work is on the theory and design of event-triggered control for uncertain and nonlinear plants — with emphasis on Linear Parameter-Varying (LPV) models and robust control under actuator saturation. I work comfortably with Lyapunov stability, LMI-based design, and rigorous proofs, and I review for the same venues I publish in.
